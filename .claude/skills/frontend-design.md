# Frontend Design Skill

Create distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics.

## Design Thinking

Before coding, commit to a BOLD aesthetic direction:

- **Purpose**: What problem does this interface solve?
- **Tone**: Pick an approach (minimalist, maximalist, retro-futuristic, luxury, brutalist, etc.)
- **Differentiation**: What makes this UNFORGETTABLE?

## Guidelines

- **Typography**: Distinctive fonts. If Russian — use Cyrillic fonts
- **Color**: Cohesive palette. Dominant colors with sharp accents
- **Motion**: Animations for micro-interactions. Staggered page load reveals
- **Composition**: Unexpected layouts, asymmetry, generous negative space
- **Details**: Gradient meshes, noise textures, layered transparencies

## Avoid

- Overused fonts (Inter, Roboto, Arial)
- Purple gradients
- Predictable layouts
- Cookie-cutter designs
