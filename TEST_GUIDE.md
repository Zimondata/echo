# Руководство по тестированию Echo Bot

## 🤖 Как найти бота

Найди своего бота в Telegram по username, который ты указал при создании через @BotFather

## ✅ Тестовые сценарии

### 1. Базовые команды

#### /start
```
Ожидаемый ответ:
Привет, [твоё имя]! 👋

Я *Echo* — твой AI-ассистент для управления дневником, идеями и планами.

Я умею:
📔 Вести дневник твоих мыслей
💡 Сохранять идеи и инсайты
📅 Планировать задачи и события
🔔 Напоминать о важном

Просто отправь мне голосовое или текстовое сообщение, и я всё сохраню!

Используй /help для подробной информации.
```

#### /help
Должен показать список всех команд и примеры использования

#### /status
Должен показать статистику твоих записей (сначала будет 0)

#### /settings
Должен показать текущие настройки (язык, таймзона, Google Calendar статус)

---

### 2. Текстовые сообщения

#### Тест 1: Дневниковая запись
**Отправь:**
```
Сегодня был отличный день, завершил важный проект и получил позитивный фидбек от команды
```

**Ожидается:**
- Бот анализирует сообщение через GPT-4
- Определяет тип: Дневник (📔)
- Возвращает подтверждение с резюме

#### Тест 2: Идея
**Отправь:**
```
У меня идея создать AI-инструмент для автоматизации планирования встреч
```

**Ожидается:**
- Тип: Идея (💡)
- Сохраняется в базу
- Возвращает подтверждение

#### Тест 3: План с датой
**Отправь:**
```
Завтра в 14:00 встреча с клиентом по новому проекту
```

**Ожидается:**
- Тип: План (📅)
- Создаётся событие в календаре
- Создаётся напоминание
- Показывается время события и напоминания

---

### 3. Голосовые сообщения

#### Тест 4: Голосовое сообщение
**Отправь голосовое сообщение:**
Наговори что-нибудь на русском, например:
"Сегодня я узнал интересный факт о машинном обучении"

**Ожидается:**
1. Сообщение "🎤 Обрабатываю голосовое сообщение..."
2. Транскрипция через Whisper API
3. Анализ через GPT-4
4. Сохранение и подтверждение

---

## 🔍 Проверка в базе данных

После отправки нескольких сообщений, проверь что они сохранились:

```bash

```


## 🐛 Troubleshooting

### Бот не отвечает
1. Проверь что Rails сервер запущен:
   ```bash
   curl http://localhost:3000/up
   ```

2. Проверь что ngrok работает:
   ```bash
   curl http://localhost:4040/api/tunnels
   ```

3. Проверь webhook:
   ```bash
   curl "https://api.telegram.org/bot8256898686:AAEywKcZjRzZA1mgUsaUAsflgtXBn0Xj2bA/getWebhookInfo"
   ```

### Ошибки OpenAI
Проверь:
- API ключ правильный в `.env`
- Есть баланс на счету: https://platform.openai.com/account/billing/overview
- Проверь логи: `tail -f log/development.log`

### Whisper не работает
- Telegram отправляет голосовые в формате .ogg
- Проверь что файл скачивается (смотри логи)
- Убедись что OpenAI API доступен

## 📈 Метрики производительности

Следи за временем обработки:
- Получение webhook: ~50ms
- Whisper транскрипция: 1-2 секунды
- GPT-4 анализ: 1-2 секунды
- Сохранение в базу: ~50ms
- **Общее время: 2-4 секунды**
