# Echo - Quick Start Guide

## 🎉 Что готово

Базовая версия Echo готова к тестированию! Вот что уже работает:

### ✅ Реализованные функции:

1. **Telegram Bot Integration**
   - Прием текстовых и голосовых сообщений
   - Webhook endpoint
   - Команды: `/start`, `/help`, `/settings`, `/status`

2. **AI Processing**
   - Speech-to-text через Whisper API
   - Анализ контента через GPT-4
   - Автоматическое определение типа (дневник/идея/план)
   - Извлечение дат и создание напоминаний

3. **Database**
   - PostgreSQL с pgvector
   - Модели: User, Entry, CalendarEvent, Reminder
   - Векторный поиск готов для будущих фич

4. **Background Jobs**
   - Асинхронная обработка сообщений
   - Автоматическая отправка напоминаний каждую минуту

## 🚀 Запуск за 5 минут

### Шаг 1: Получить API ключи

#### 1.1 Telegram Bot Token
```bash
# 1. Открой Telegram и найди @BotFather
# 2. Отправь: /newbot
# 3. Следуй инструкциям
# 4. Скопируй полученный токен
```

#### 1.2 OpenAI API Key
```bash
# 1. Зайди на https://platform.openai.com/api-keys
# 2. Создай новый ключ
# 3. Скопируй его
```

### Шаг 2: Настроить Rails credentials

```bash
# Открой Rails credentials для редактирования
EDITOR="nano" bin/rails credentials:edit

# Добавь свои ключи в файл:
telegram:
  bot_token: твой_telegram_токен
openai:
  api_key: твой_openai_ключ
```

### Шаг 3: Установить ngrok для локального тестирования

```bash
# Установить ngrok
brew install ngrok

# Запустить ngrok (в отдельном терминале)
ngrok http 3000
```

Скопируй HTTPS URL (например: `https://abc123.ngrok.io`)

### Шаг 4: Установить webhook

```bash
# Замени <YOUR_BOT_TOKEN> и <YOUR_NGROK_URL>
curl -X POST "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook" \
  -d "url=<YOUR_NGROK_URL>/telegram/webhook"

# Проверить webhook
curl "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getWebhookInfo"
```

### Шаг 5: Запустить приложение

```bash
# Запустить Rails сервер
bin/dev
```

### Шаг 6: Протестировать!

Открой своего бота в Telegram и отправь `/start`

## 📱 Как использовать

### Команды:

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/settings` - Посмотреть настройки
- `/status` - Статистика записей

### Примеры использования:

#### 1. Дневниковая запись (текст):
```
Сегодня был продуктивный день. Закончил важный проект и получил отличный фидбек от команды.
```

Бот ответит:
```
📔 Записал!

Тип: Дневник
Дата: 13 октября 2025, 15:30

Резюме:
Продуктивный день с завершением важного проекта и позитивным фидбеком от команды.
```

#### 2. Идея (голосовое сообщение):
🎤 "У меня возникла идея создать AI-инструмент для автоматизации планирования встреч"

Бот ответит:
```
💡 Записал!

Тип: Идея
Дата: 13 октября 2025, 15:35

Резюме:
Создание AI-инструмента для автоматизации планирования встреч.
```

#### 3. План с напоминанием (текст):
```
Завтра в 14:00 встреча с клиентом по новому проекту
```

Бот ответит:
```
📅 Записал!

Тип: План
Дата: 13 октября 2025, 15:40

Резюме:
Встреча с клиентом по новому проекту завтра в 14:00.

📅 Создал событие в календаре на 14 окт., 14:00
🔔 Напомню тебе 14 окт., 13:30
```

## 🔧 Troubleshooting

### Бот не отвечает

1. **Проверь webhook:**
```bash
curl "https://api.telegram.org/bot<YOUR_TOKEN>/getWebhookInfo"
```

Должен быть статус: `"url": "https://your-ngrok-url.ngrok.io/telegram/webhook"`

2. **Проверь логи:**
```bash
tail -f log/development.log
```

3. **Проверь ngrok:**
- ngrok должен быть запущен
- URL не должен измениться

### Ошибка "OpenAI API Key not found"

```bash
# Проверь Rails credentials
bin/rails credentials:show | grep openai

# Если ключа нет, добавь его:
EDITOR="nano" bin/rails credentials:edit

# Перезапусти сервер
bin/dev
```

### PostgreSQL не запущен

```bash
brew services start postgresql@17
```

### Whisper не распознает русский язык

В файле `app/services/ai/whisper_service.rb` язык уже установлен на `"ru"`. Если нужен другой язык, измени параметр `language:` в методе `transcribe`.

## 📊 Архитектура

```
Telegram Message
    ↓
TelegramController (webhook)
    ↓
TelegramWebhookJob (async)
    ↓
Telegram::MessageHandler
    ↓
    ├─→ Ai::WhisperService (если голос)
    └─→ Ai::ContentAnalyzer (GPT-4)
        ↓
        Entry.create!
        ↓
        ├─→ CalendarEvent (если план)
        └─→ Reminder (если нужно)

Background:
SendRemindersJob (каждую минуту)
    ↓
Telegram::BotService.send_message
```

## 💡 Советы по использованию

### Лучшие практики:

1. **Говори естественно** - бот понимает разговорный язык
2. **Указывай даты явно** - "завтра в 14:00" работает лучше чем "во второй половине дня"
3. **Используй команды** - `/status` покажет твою активность
4. **Добавляй контекст** - чем больше деталей, тем лучше AI понимает

### Примеры хороших запросов:

✅ "Завтра в 10 утра созвон с командой по квартальным результатам"
✅ "У меня идея: создать бот для автоматизации рутинных задач"
✅ "Сегодня узнал интересный факт о машинном обучении..."

### Примеры не очень хороших:

❌ "Созвон" (непонятно когда)
❌ "Идея про бота" (слишком кратко)
❌ "Было хорошо" (мало контекста)

## 🔐 Безопасность

- API ключи хранятся в Rails credentials (`config/credentials.yml.enc`) - зашифрованы и безопасны
- Файл `config/master.key` не должен коммититься в git (уже в .gitignore)
- PostgreSQL работает локально
- Webhook использует HTTPS через ngrok
- Все данные только у тебя
